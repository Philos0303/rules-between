# 第一夜洋楼：摆放与观察位说明

> 依据：[placements.json](placements.json)与[geometry.json](geometry.json)。2026-10-21整理时从当前源数据同步；下列通行宽度是设计预留，不代表已完成碰撞或人体尺度验收。

## 坐标与使用

使用世界米制X东/Y北/Z上。position是物件底面中心，footprint是平面占地；rotation_z_degrees控制朝向。collision:false的挂件、纸张和虚拟证据不作为实体阻挡。动态门、窗帘、抽屉、电话、镜子、灯和热点保持独立。

相机只给出设计观察位，不是运行时固定镜头。逐物尺寸、相机和marker见JSON及[逐场景资料](scenes/)。不要从概念图新增开口或移动线索。
