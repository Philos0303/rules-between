# 第一夜关键交互：建模与状态交接

> 依据：第一夜完整游玩流程 v1.0 与 `scene-content.json`。
> 坐标规则：几何代理调整中，全部位置只引用房间 ID、墙面/地面基准和相邻物；不在本文写死世界坐标。
> 目标：为高精度 Blender 源和轻量 目标引擎 装配提供同一套可检查的拆件、状态、证据与退路。

## 通用边界

- Blender 高精度源可含完整门框、五金和陈设细节；运行时资产另导出经过预算控制的网格。
- 低模灰盒、AI 参考图和镜景平面都不是生产完成的高精度资产。
- 交互件与静态壳分离：门扇、窗帘、抽屉、镜托、电话活动部件、盒盖和灯具由 目标引擎 控制。
- 每个动态件具独立 pivot、闭合状态为默认变换、明确开合轴或滑轨轴；不可依靠骨骼布料或物理模拟。
- 关键证据在正常光照、低亮度、关闭声音和减少动态效果时都必须仍可辨认。
- 任何“观察前沿”都由 目标引擎 blocker 管理，Blender 只提供准确门框、地面和可读的环境线索。
- 尺寸均为建议实尺，平面冻结后以房间正交尺寸为准；不得为容纳道具改变既定门洞或路线。

## INT-01 楼梯换鞋凳、双挡抽屉与旧手镜（S）

- 组成：`dyn_drawer_bench_lower`、右内侧木挡、第二挡止位、擦鞋布、`hero_mirror_hand_01`、可拆 `dyn_mirror_stand_s`。
- 换鞋凳建议 1.05 × 0.38 × 0.47 m，靠 S 的指定墙面放置；抽屉净高至少 0.12 m，允许手镜平放。
- 抽屉 pivot 在滑轨起点，沿凳子短向单轴移动；第一挡约 0.18 m，第二挡约 0.31 m，止位应可见且可触。
- 木挡为 18–25 mm 厚小压片，装在抽屉右内壁，按下后才允许第二挡；不做数字锁、密码或复杂机关。
- 手镜为日常旧银色/镀镍椭圆手镜，建议总长 0.22–0.26 m、镜面约 0.11 × 0.15 m、厚 8–12 mm。
- 手镜必须有金属边框、短柄、轻微使用划痕和背板雕纹；不发光、不漂浮、不带神秘符号。
- 状态：`closed` → `first_stop` → `latch_inspected` → `second_stop` → `mirror_taken`；物件实体只在暗格、背包或镜托之一出现。
- 证据：第一眼只看见擦鞋布；近看能看出抽屉内深与外观不符；按木挡后可见第二道滑轨。
- 安全退路：任意阶段可关抽屉或离开，未满足条件不扣污染、不锁死；镜子最早 N4 才显示旧景。

## INT-02 固定镜景 V1：书房旧柜痕迹（F4）

- 组成：`dyn_mirror_stand_v1`、`marker_v1_mirror_view`、柜脚压痕、墙面浅矩形、镜景平面 `view_v1_old_cabinet`。
- 镜托位于 F4 指定观察侧，面向旧柜缺席的墙面；不得挡住 F3–F8 的正常通行。
- 镜托台面建议 0.72–0.82 m 高，托槽宽约 0.13 m；手镜放置后固定为预设角度，不要求玩家自由调角。
- V1 镜中只显示旧柜的大轮廓；镜外同时保留现实柜脚压痕和墙印，构成两处对应证据。
- 状态：`unavailable_pre_n4` / `ready` / `viewing` / `verified`；`verified` 只记录“镜景属于过去”，不打开门。
- 镜面采用固定镜头画中画或作者制作静帧，淡入约 1 s；不要做实时全场反射或第二套完整书房。
- 安全退路：放下镜子即可回到现代书房；无跨门和死亡分支。

## INT-03 固定镜景 V2：原主卧旧门与实体墙（U5）

- 组成：`dyn_mirror_stand_v2`、`marker_v2_mirror_view`、梳妆台、实体完整外墙、镜景平面 `view_v2_old_door`。
- 梳妆台建议 1.00 × 0.42 × 0.78 m，镜托设置于其原有小托位；不加巨大落地镜。
- 镜中旧门宽约 0.78–0.85 m，门框与旧椅/遮光布为过去静帧构图；正常 M 壳体仍为完整墙体。
- 状态：`ready` → `viewing` → `old_door_seen`，随后出现“向前确认”的观察前沿，前沿不是真实可走门。
- 证据：实体墙的修补层、镜中门框、空椅三者同时可读；镜中不出现可互动人影。
- 首次跨入错误前沿由 目标引擎 给出 X1 警告与可撤回点；第二次明确“继续穿过”才可结算迷失死亡。
- 安全退路：收镜、转身回 U1，或经 U8 回到电话厅；该条绕行正是 N5 的安全路线。

## INT-04 固定镜景 V3：楼梯补缝与历史门（S）

- 组成：`dyn_mirror_stand_s`、`marker_v3_mirror_view`、补漆墙、旧砖/门框镜景 `view_v3_history_threshold`。
- V3 对着 S 的指定补缝墙，历史门需要至少 2.05 m 的净高，不能挤在低斜梯底。
- 现实中保持完整补缝墙；镜中仅显示旧门框和旧砖缝，镜外显示对应修补缝，至少两项大形状对位。
- 状态：`silhouette_only`（未完成 V1/V2 或未到 N8）→ `aligned_for_check` → `threshold_checked` → `history_door_open`。
- `history_door_open` 由流程状态决定，镜子只提供定位和稳定观察，不是万能判真工具，也不持续维持门开启。
- 入口跨越前仍须检查门内外砖缝、门框和光源关系；Blender 提供这些可读表面，目标引擎 处理门槛对齐、blocker 和结果。
- 安全退路：未对齐时可收镜离开；跨越错误门槛遵从 X1 两段确认和最近稳定点恢复。

## INT-05 电话、听筒与杯碟声源证据（U6）

- 组成：电话机身、听筒、叉簧、可见铃锤/铃盒件、桌面杯碟、`marker_phone_check`。
- 电话桌建议 0.72 × 0.40 × 0.75 m；电话位于桌面前侧，杯碟分开摆放，二者不可被装饰遮住。
- 听筒 pivot 在叉簧落点，玩家“拿起/挂回”使用单一位置状态，不制作手部模型；线缆为静态曲线或低段数网格。
- 铃锤与杯碟为独立动态引用件：第一次来电时它们与声音同步，之后走廊复制声出现时二者都静止。
- 状态：`idle` → `source_ringing` → `handset_lifted` → `source_stopped` → `copy_heard` → `verified`。
- 证据必须具备可视同步、播放状态和字幕来源描述三种通道，不能只靠听声线猜测。
- 安全退路：电话停止后可挂回、停在桌前或回 U1；追随无源声音才进入 X3 警告，未有倒计时。

## INT-06 配电箱、透明钥匙盒与服务钥匙（F8）

- 组成：`dyn_breaker_box_door`、断路器拨杆、`dyn_key_box_door`、I2 钥匙圈、维护标签、`marker_power_panel`。
- 配电箱约 0.55 × 0.16 × 0.70 m，中心建议 1.35–1.55 m 高；钥匙盒约 0.22 × 0.10 × 0.28 m，安装在同墙可见范围。
- 箱盖和钥匙盒盖均用单轴铰链 pivot；门盖开角不侵入 F8 至 F1/F4/F7/F9 的行走净空。
- I2 是短钥匙圈，不做逐把试锁；盒内有清晰维护说明，N0 提前取走合法但不推进事件。
- 状态：`box_visible` → `key_box_open` → `key_taken` → `panel_open` → `breaker_reset` → `power_safe`。
- 证据：现代门锁和窗外路灯正常，说明本次可安全恢复室内电路；开关标签与拨杆位置可见。
- 安全退路：查看、提前取钥匙、打开箱盖均安全；不设计触电、接线、限时拨杆或额外死亡。

## INT-07 客厅灯、餐厅窗帘与搭扣（F2/F3）

- 组成：`dyn_light_living`、`dyn_curtain_dining_left/right`、下摆搭扣、窗框、可见窗线与漏光带。
- F2 台灯为单开关实体，灯罩和灯座不必做动态高模；光照开关由 目标引擎 控制，模型仅保留开关位置。
- F3 双层帘分左右两片，沿上方直轨单轴平移；禁止布料模拟和任意抓取。
- 下摆搭扣设在指定侧，建议 25–35 mm 见方；闭合后形成连续遮光轮廓，视觉上不得有模糊“似乎关好”。
- 状态：`curtain_open` / `curtain_closed_unlatched` / `curtain_sealed`；灯为 `off` / `on_safe` / `on_exposed`。
- N2 的现代断电可以直接复位后开灯；N7 必须先得到 `curtain_sealed`，再开灯才进入 `on_safe`。
- 证据：帘缝、外部暗化、窗框轮廓和搭扣位置均可近看；不靠红绿颜色判定。
- 安全退路：灯开而帘未封只进入 X2 警告，可关灯或扣好窗帘解除；再次调亮才是致命确认。

## INT-08 厨房窗内衬、后门与遮光钉孔（F5/O2）

- 组成：`dyn_curtain_kitchen_liner`、现代窗帘、旧钉孔贴花/浅几何、后门内侧插销、`marker_kitchen_blackout_trace`。
- 内衬是可翻开的薄布/板状静态件，绕上沿小轴旋转；不使用布料模拟，翻开后停在预设角度。
- 钉孔与窗框的相对位置须从 F5 室内和 O2 后院都能复查，作为 D1 的物理依据。
- 厨房后门门框属于静态壳；插销和门扇作为动态引用件，内侧开闩后允许正常进入 O2。
- 状态：`liner_closed` → `liner_inspected` → `nail_holes_seen`；后门 `latched_inside` → `unlatched`。
- 证据：旧遮光痕迹解释“光不能越过窗线”的条件，不将厨房整间切换成可走 W 场景。
- 安全退路：翻回内衬、查看钉孔、开后门都安全；不因早期调查提早触发遮光死亡。

## INT-09 树根、排水沟与重复箭头假门（O4）

- 组成：树池、可读树根、连续明沟、墙面林远箭头、`marker_o4_tree`、`marker_o4_drain`、G 假门平面。
- 树池约 1.60 × 1.60 × 0.40 m，树根需有两个可辨大分叉；明沟边缘须从 O3 入场与 O5 回程两方向可见。
- 箭头是低对比漆痕/贴花，不能比树根和沟沿更显眼；G 副本仅出现在无通路墙面。
- 假门为观察前沿立面，不建第二室内、走廊或可探索空间；其门框不能替换正常 O4→O5 出口。
- 状态：`anchors_unchecked` → `anchors_checked` → `safe_route_seen`；假门 `hidden` / `visible_warning` / `blocked`。
- 证据：树根与沟沿是两个独立固定锚点，箭头只是可被复制的经验；玩家可从形状、方位和连续性判断。
- 安全退路：向正常 O5 门离开或退回 O3 均安全；进入假门前沿先 +8 警告，明确继续才触发 X4。

## INT-10 前院院门、街灯与外部断接（O1）

- 组成：`dyn_gate_front`、内侧锁扣、门框、街灯底座、排水沟延续、`marker_gate_threshold`。
- 院门为真实可开铁门，铰链 pivot 在柱侧；开到观察位置时不穿墙、不夹玩家，门外边界由 目标引擎 管理。
- N1/N2 状态为 `latch_stuck`，提供故障文字；N3 后为 `gate_observe_g`，可看路牌和排水沟错位。
- 清晨状态为 `gate_open_m`，街灯底座与沟沿连续，作为真实出口的两项外部证据之一。
- 证据：门外路牌/沟沿关系、门框地面连续、街灯底座；暖光本身永远不能作为真晨唯一判据。
- 安全退路：观察后可取消并退回 O1；选择“走向路灯”只短黑场送回 O1，首次 +5，不构成死亡或新地图。

## INT-11 林远录音机与外圈图（F10）

- 依据：`interactions.json` 的 INT-11；值班桌面近前侧，播放器与纸图从门内第一视角可辨认。
- 组成：`hero_recorder_01`、`prop_route_map_01`、`dyn_recorder_play_control`、`marker_recorder_check`。
- 值班桌建议1.05×0.50×0.75m；录音机最大包络0.22×0.14×0.08m。播放控制为短行程按键或拨杆，不做调频。
- 状态：`on_table` / `playing` / `paused` / `taken` / `silhouette_left`。
- 证据：播放指示、逐句字幕或可读转录、桌面外圈图。可暂停、重听与离开；设备静止时不能把外部同声当成它在播放。

## 操作顺序与模型验收

1. F8 取 I2 / 复位电箱 → F5 检查内衬与后门 → O2 核对钉孔。
2. U6 验证电话实体声源，面对无源复制时可退回；通过 U8/U5 绕过短廊错位。
3. F10 播放或阅读林远录音，确认外圈“树与水沟”比箭头可靠；设备静止时不把外部声音当成它在播放。
4. O4 核对树根与沟沿，避开重复箭头假门，经 O5 回 O1。
5. S 用双挡抽屉取得 I4；N4 后可做 V1，继而 V2；N8 后才可在 V3 检查入口。
6. N7 在 F3 扣好窗帘搭扣，再回 F2 开灯；最后在 O1 复核真实清晨出口。

- 验收时逐个记录每一动态件的 pivot 轴、闭合变换、开启角/距离、碰撞间隙和玩家可见证据。
- 检查镜子在暗格/背包/镜托只出现一次；三个镜景均为固定观察内容，绝不导出实时世界镜面。
- 检查所有警告前沿都有退回方向、文字确认和最近稳定点；模型本身不隐藏死亡判据。
- 任何优化版 GLB 都须回查上述操作顺序；减面、合批或烘焙不能删除门框内侧、帘缝、钉孔、杯碟、树根或沟沿。
