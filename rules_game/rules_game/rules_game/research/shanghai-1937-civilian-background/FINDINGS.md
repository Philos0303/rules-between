# 1937年上海普通人战争背景

## Summary

淞沪会战自1937年8月13日起持续约三个月，上海不同管辖区的风险和生活状态并不相同。法租界与公共租界一度成为相对安全但高度拥挤的避难区域，边界封锁、难民涌入、物资压力、远处战火和偶发轰炸可以同时存在。游戏宜把洋楼设在法租界西部或边缘的虚构里弄，以“相对安全区内仍被战争压迫的日常”为背景，不直接复刻具体惨案或战斗。

## Findings

1937年8月13日淞沪会战爆发并持续约三个月。战火、轰炸和人口移动深刻改变上海普通居民的生活。上海淞沪抗战相关纪念机构和国防部资料均确认了战役的时间范围与严重破坏。

租界并非与战争隔绝。法国国防影像档案所述战地记录提到法租界屋顶可见轰炸，且大量难民涌入；有关上海战争难民的学术研究记录了法租界边界增设铁丝网、防御工事和边界控制。Virtual Shanghai保存了1937年被轰炸区域、人口移动、难民营与法租界防御墙等历史地图索引。

1937年12月英国议会记录估计，上海南市、公共租界和法租界分别约有25万、10万和5万难民，说明战争造成的大规模人口与救济压力。虹口区政府史料还记录了夜间租界灯火与闸北火光同时映亮天空的情形，适合用作“相对安全的室内生活与近在眼前的战争”之间的视觉反差。

游戏无需指定真实门牌。将虚构洋楼放在法租界西部或边缘，可以合理承载相对完整的富裕住宅、突然失联的家人、边界封锁、避难者消息、远处炮火与城市声场变化，同时避免把一个真实惨案现场娱乐化。

## Insights

- “富家女人仍然无力”的主题，在相对安全区比直接战区更清楚：房屋和物资能延缓危险，却不能恢复交通、信息与选择。
- 门槛、遮光、广播、声音和错误路线都能从城市边界与战争日常中获得现实原型，不需要出现士兵、战斗关卡或宏大战争镜头。
- 采用虚构街区和合成住宅能保留史实压力，又避免把单一虚构角色错误地绑定到真实遇难者身份。

## Strongest objection

把战争记忆包装成规则怪谈，容易把真实苦难审美化。设计必须让战争细节服务于普通生活被压缩的过程，避免把轰炸、难民和伤亡做成刺激性奇观或收集品。
