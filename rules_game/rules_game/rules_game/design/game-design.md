# 《规则之间》完整设计基线

- 整理日期：2026-10-21。合并整体设计v6.1与本次确认保留的第一夜完整方案。
- 类型：第一人称3D心理恐怖、环境推理、规则验证；Windows键鼠优先，买断制，个人开发。
- 当前确认范围：第一夜表里双线、人物、事件、失败恢复及洋楼空间。
- 详细动作与Q01–Q20验收：[第一夜完整流程](first-night.md)；空间资料：[场景入口](scene/README.md)。
- 第二夜：[保留方向](second-night-direction.md)，具体关卡尚未完成设计。本文不宣称已有可玩版本。

## 1. 一句话概念

玩家黄昏自助入住上海一栋由战时私人旧宅翻修的小型民宿，在异常中发现前人规则彼此矛盾。他必须核对这些经验成立的时间与空间条件，在现代民宿、战时回放和梦核夹缝中保住返回的位置；可以清晨安全离开，也可以追查旧手镜与两位前人的痕迹，主动继续了解异常保存的普通生活。

## 2. 设计支柱与范围

恐怖从可信的生活故障逐步生长；规则是带条件的证词；同一地点承担现代、战时和夹缝三种意义；危险必须公平可撤回；制作规模服从个人开发能力。

1. 异常没有人格、恶意、幕后操纵者或可战胜的怪物，是战争记忆的机械回放。
2. 规则来自前人局部经验；每条失效经验都曾在具体条件下成立，不随机换答案。
3. 玩家通过观察、核对、操作、退回和记录解决危险。没有战斗、追逐、潜行、QTE和自由组合背包。
4. 异常先是可以解释的小故障，再逐步扩大；高污染不能提前跳过章节表现上限。
5. 同一洋楼与既有院落承载M/W/G，不制作三张独立地图或第二张大型户外地图。
6. 第一夜不依赖历史调查也能安全完成。历史入口必须通过实际调查取得，不能清晨自动赠送。
7. 全游戏保留“离开”“见证”两个正式结局方向；迷失是可重试失败，入口预告不是第三个结局。
8. 不做可见怪物、完整NPC模型、正面战争、尸体陈列、姓名拼合或家族调查支线。
9. 第一夜只有一座主楼梯，没有地下室、服务楼梯、随机迷宫或围挡外可玩街区。
10. 固定四条真实规律和八条主要前人经验，不为新增内容发明第五条规律。

## 3. 世界真相与人物

场景是上海虚构街区的一栋战前旧私人住宅，现代翻修为四客房自助民宿。历史方向为1937年淞沪会战期间，家人失联、交通受阻、遮光、物资与消息压力侵入日常。建筑不复刻真实门牌，不使用真实遇难者作为谜题身份。广播、警报、家庭电话形制及灯火管制仍须正式制作前逐项查证，研究见[历史背景](../research/shanghai-1937-civilian-background/FINDINGS.md)。

异常反复把站在相同位置、执行相似动作的人填入旧记忆空位。玩家没有特殊血统或使命，只是在入住后完成与旧生活重合的普通动作而被卷入。

| 人物 | 职责与经历 | 呈现边界 |
| --- | --- | --- |
| 玩家 | 普通现代住客，无特殊身份；判断由玩家本人完成 | 第一人称、呼吸与短句笔记，无战斗或长篇独白 |
| 战时无名女人 | 二十余岁，家庭条件较好；父母在外，独自应付失联、遮光与等待 | 电话短句、日用品与生活残留；不确认完整身世和最终命运 |
| 更早女性探索者 | 留下原始记录与手镜；曾找到有效办法，后来继续执行失效经验而迷失 | 二号客房、旧纸、重复抄写和行李；不是战时女人 |
| 林远 | 整理生存经验，第一夜确实找到出口；用过并归还手镜，主动进入历史，第二夜因污染迷失 | 固定录音、整理页与末页；不是实时通话者，也不确认死亡 |

无名女人不是Boss、幕后出题者或待拯救对象。后续见证方向是理解记忆关系，并停止回应无源呼唤和错误出口，让回放自然结束；不改写历史，不替她实现愿望。

## 4. 玩家动词与核心循环

| 动词 | 用途 |
| --- | --- |
| 观察与倾听 | 看门缝、窗线、墙脚、器械与空间关系；声音有非音频证据 |
| 核对 | 比较两个独立证据，而非照抄规则 |
| 操作 | 门、灯、窗帘、电话、少量固定物与镜托 |
| 退回 | 沿最后连续门槛返回稳定位置，始终是合法策略 |
| 记录 | 分开保留前人原文与现场事实，不自动给标准答案 |

30秒循环：察觉不一致 → 靠近检查 → 找到第二项证据 → 判断连续性 → 操作或退回 → 留下可复查反馈。

数分钟循环：现实需求促使离房 → 遇到异常 → 读到前人经验 → 核对条件 → 打开路线或得到人物痕迹 → 重访熟悉地点。

操作只需移动、观察/交互、笔记和暂停。“开至观察位”和“跨越”分别确认。物品自动使用，手电不耗电；不做自由绘画、搬家具或物理合成。手镜只在固定三处显示作者制作的旧景，不做全场实时反射、自由调角或手部模型。

## 5. 三种状态与四条规律

| 状态 | 识别依据 |
| --- | --- |
| M现代民宿 | 门锁、现代装修、城市声、灯具和空间关系一致 |
| W战时回放 | 旧门锁、遮光、生活器械及用途彼此一致；过去本身不等于危险 |
| G梦核夹缝 | 门内外时代不接、无源声重复、锚点复制或连接关系颠倒 |

| 规律 | 现场判断 |
| --- | --- |
| T1门槛连续 | 两侧稳定同层，地面、门框、光源关系相接才跨越；敲门次数和声线不能替代 |
| T2遮光边界 | W遮光阶段不让室内光越过窗线；封帘后室内灯仍可用 |
| T3实体声源 | 器械动作与播放状态和声音同步，才证明声音来自那里；录音不代表本人在场 |
| T4连续路径 | 两个固定地标的方位与连接一致才前进，错位时退回最后稳定处 |

异常采用预兆、现实问题、前人经验、现场验证、结果、残留六段结构。严重承诺前至少有两类证据和可见退路；观察不自动触发危险。相同条件与动作在重试后保持一致。

## 7. 第一夜完整结构

表线闭环：入住受困 → 相信林远 → 发现经验需要现场验证 → 走通外圈 → 完成遮光回放 → 验证真实清晨并安全离开。

里线闭环：追查另一笔迹 → 理解早期住客的有效经验与失误 → 找到同一面手镜 → 核对三处旧景 → 发现林远本来可以离开却主动继续 → 定位历史入口。

| 阶段 | 故事钟 | 核心行动 |
| --- | --- | --- |
| N0 | 17:40 | 自助入住、正常生活基线、客房休息 |
| N1 | 20:30/21:10 | 热水故障、首敲、第一次保住门槛 |
| N2 | 22:00 | 现代断电，核对证据后安全复位；取得服务钥匙 |
| N3 | 23:00 | 三轮敲门，识破次数不能保证连续 |
| N4 | 00:10 | 电话实体同步与停止后的无源重复 |
| N5 | 01:20 | 识别短廊复制，退回并经阳台/原主卧绕行 |
| N6 | 02:40 | 走后院—侧巷—树院—后勤院，识别假箭头 |
| N7 | 04:30 | 封帘、扣搭扣、恢复安全灯、核对无源声与门槛 |
| N8 | 05:50 | 核对真实清晨，可安全离开或补完调查 |

故事钟按动作推进，不随现实阅读时间流逝。第一夜表线目标65–85分钟，完整里线85–115分钟，均待灰盒实测；不沿用旧整体90–110分钟预算。

里线推荐：H1厨房窗帘与钉孔 → H2二号房原记录 → H3楼梯双挡抽屉取镜 → V1书房旧柜与现实痕迹 → V2原主卧旧门与完整墙面 → V3楼梯补缝、旧门轮廓与W/W对齐。H1/H2提供发现路径，不是必须收齐的纸张数。认真检查提前找到镜子合法，N4前镜子只显示普通反光。

清晨可补全部调查，没有倒计时。未调查时历史墙保持普通墙面；资格取得后可收镜离开，但再次进入仍需核对当前门槛。

## 8. 洋楼空间与内容量

25个功能节点：一层F1–F10、唯一主楼梯S、二层U1–U8、室外O1–O6。O6为围挡后的可见街角，不能步入。住宿房只有U2–U5。

- 一层生活环：F1—F2—F3—F4—F8—F1。
- 外圈：F5—O2—O3—O4—O5—F9—F8；O5—O1—F1形成返回捷径。
- 二层绕行：U6—U8—U5—U1，替代N5错位的U6—U1。
- 镜位：F4旧柜、U5梳妆台/旧门、S完整高度补缝墙。
- 唯一几何：[geometry.json](scene/geometry.json)；唯一摆放：[placements.json](scene/placements.json)。
- 逐步路线与观察证据：[流程与布局合同](scene/layout-reference/flow-layout-contract.md)。

建筑不对称，生活主楼、有限后勤翼、前后院、侧巷和树院连在同一骨架。四间客房复用床柜套件；小间不各自做谜题；街角外缘不是当前主线门槛。尺寸、门窗、楼板洞和观察区有设计数据，但仍需胶囊体实走、视线和门扇扫掠验证。

第一夜W只做电话桌残留、三幅定点旧景、N7生活区和门槛旧材质。G只复用短廊三状态、假门立面与局部错接，不增加真房间。

制作单元为小错位、首敲、现代停电、三敲、电话复制、短廊回路、院落箭头、最终遮光八组主异常。物品I0–I4：手机、小手电、服务钥匙圈、林远录音机、旧手镜。文本为八条经验、D0–D7及按事件产生的事实笔记。

## 9. 污染、危险与恢复

P为0–100整数，F为阶段下限。正确判断与稳定整理可降低P但不能低于F。没有按现实停留时间涨污染；观察、阅读、听录音、镜面查看、慢走和暂停安全。

| 结算 | 数值与约束 |
| --- | --- |
| 阶段进入 | P=max(P,F_new)，每阶段一次 |
| 首次夜间试院门 | 整夜一次+5，最高99，只软返回 |
| 首次跨入已预告错误前沿 | +8，最高99，保留退路；同遭遇不反复扣首次值 |
| 正确完成A32/A39/A45 | 各-8，一次有效，不低于F |
| 稳定点整理 | 每阶段一次-12，不跳剧情、不清危险 |
| 警告后再确认致命动作 | P=100，进入迷失恢复 |
| 读档 | P=max(F_saved,min(P_saved,F_saved+8)) |

X1断裂门槛、X2漏光后继续调亮、X3追无源声、X4坚持失效路线共用4–6秒可跳过的低刺激失败流程。首次错误永远有退路；没有现实时间伤害，危险同时最多一个。各动作、原因与解除方式以第一夜§8为准。

表现档0–19/20–39/40–59/60–79/80–99；章节表现上限独立控制。污染不遮挡关键证据，不使正确动作变错。

## 10. 保存与结束

C0–C8保存稳定快照，不在危险前沿、G内部或状态动画中写位置。物品取得、世界显隐、归属和存档原子提交；知识可保留，但读过文字不生成物品。镜子只在暗格、背包或一个镜托之一。

E1“离开”在清晨验证出口并确认跨出时记录；随后06:10醒来是无危险尾声，可跳过。尾声不覆盖C8。完成后“回到清晨”返回实际保存状态，不赠镜子或调查资格。

历史入口要求清晨、取得镜子、V1/V2实际比对、V3墙面检查与门槛对齐。资格持久，当前对齐和开门状态随离开清除。第一夜独立版本只显示明确“当前版本到此结束”的历史入口预告，不提供空的第二夜按钮。

## 11. 第二夜与最终见证

继续使用同一洋楼与院巷。保留方向是：在连续W主动开门；组合遮光与广播；识破林远声音和箭头复制；看见女人被战争压缩的普通生活；以四律完成综合检验；停止补入记忆角色，让回放结束，梦醒并完成“见证”。

[第二夜方向](second-night-direction.md)保留原完整设计的章节意图，参数与路线未纳入本次确认。需要在当前骨架重新设计，不恢复旧服务梯、地下空间或公寓S1–S5。女人不被命名、拯救或改写命运；保留普通人的无力，不做英雄化说明。

## 12. 视觉、声音与可访问性

现代是仍在营业、干净但多次修缮的民宿；战时通过用途、门锁、遮光和日用品变化表达，不能只用滤镜。夹缝来自关系错接，保持导航清楚，不持续闪烁或摇镜。

关键声音有字幕与方向说明，实体播放有可见器械动作，复制声与其在方向、混响或延迟上稳定区分。同一时刻只播一段关键语句，长录音可读转录或跳过。

笔记分原记录、我看到的事实、未解问题。默认不用常驻精确污染百分比；提供明确分段提示、大字、字幕与减少刺激。关闭音效、辨色受限时仍可凭形状、方位、明暗和器械动作判断。视觉与制作细节见[视觉规范](scene/visual-bible.md)。

## 13. 验收与后续重构

详细流程Q01–Q20覆盖纯表线、完整里线、清晨补线、提前取物、零试错、警告/致命承诺、恢复一致性、低刺激和无声音、全图连通及O6封闭边界。

目标理解率沿用整体设计：8/10首次试玩者能理解异常是回放、规则有条件、女人是普通人且离开合理；7/10能区分林远真人与被复制声音。上述是目标，不是已完成的试玩成绩。公平性要求危险有两类证据与退路，首次错误可撤回，失败后知道原因；空间要求三组环可走、地标可见、镜子唯一且存档一致。

后续顺序：确认重构引擎与技术边界 → 现有几何灰盒实走 → 入住至规则冲突的最小完整段 → 污染与稳定恢复 → 第一夜全流程和里线 → 玩家试玩调整 → 第二夜、最终美术与正式声音。当前尚未建立新引擎工程，不用已删除原型的测试成绩代表新方案通过。
