# 第二夜保留方向

> 来源：完整设计v6.1。仅保留后续叙事和玩法方向，具体路线、坐标、时长、污染参数尚未纳入本次第一夜基线确认。旧服务梯/地下储藏依赖已移除，后续必须在当前洋楼骨架中重新落位；不据此制作关卡。

### 第二夜 A 20:30—22:00：旧规则换了条件

目标时长 7–9 分钟，`F=38`。

玄关再次敲门。这次门内外均稳定为 W，保持关闭无法推进。玩家用第一夜知识确认连续后主动开门，进入战时状态的前厅。这是“规则是条件”第一次正向应用。

第二夜从一开始就在第一夜已认识的建筑、院落与侧巷骨架中变化；它不是另一张户外地图。院落和巷道承接更多观察与路径判断，但新增的街角外缘内容仍只是一条未制作的后续接口。

### 第二夜 B 22:00—23:30：遮光与广播

目标时长 8–10 分钟，`F=50`。

远处警报与广播出现，窗外进入遮光状态。R4 要求恢复走廊灯。玩家关闭越过窗线的主灯，保留不外泄的低位照明，并找到一楼收音机这一实体声源。

客厅、餐厅和厨房开始显示战时用途：窗帘加固、食物清点、临时铺位和反复拨打电话的痕迹。后院与侧巷则通过遮光、远处广播和被挪动的杂物表达外部压力，成为本夜比第一夜更重要的观察面。玩家仍看不到女人正脸。

### 第二夜 C 23:30—01:30：林远最后路线

目标时长 9–11 分钟，`F=65`。

玩家沿林远箭头穿过后勤小院、后院和服务通道，最终抵达既有后勤储藏区。箭头起初与室内外两个锚点一致，随后被 G 复制。无源声音开始用林远的声线报出房间位置。

玩家找到林远最后一页，确认他的误判：他相信异常不能复制自己的记号和声音。玩家放弃复制箭头，利用后勤编号与楼梯地标两个锚点退回，进入稳定 W 层。

### 第二夜 D 01:30—03:40：无名女人的普通生活

目标时长 10–12 分钟，`F=72`。

玩家依次经过书房、餐厅、电话间与二楼主卧，看见四段短生活片段：等待外地消息、清点有限物资、加固遮光、在门外敲响后无法确认来者。

这些片段不要求收集完整日记。每段由空间状态、一件普通物和不超过 80 字的文字或声音构成。玩家由此确认异常来自 1937 年这段反复确认却没有答案的生活记忆。

### 第二夜 E 03:40—05:20：夹缝综合检验

目标时长 10–12 分钟，`F=82`。

G 大面积覆盖洋楼，依次复制敲门、女人声音、林远声音、箭头和错误晨光。玩家只使用已经学会的四律：

1. 拒绝穿过时代不连续的主卧门；
2. 在 W 遮光持续时阻止光线越过窗线；
3. 将真实电话、收音机和录音设备逐一静音，识别剩余声音为无源回放；
4. 用楼梯地标与后勤编号核对路线，退回最后稳定房间。

每完成一项，夹缝停止复制相应表现。这里不新增规则和道具。

### 第二夜 F 05:20—06:10：让记忆结束

目标时长 6–8 分钟，`F=88`，但正确核对可把 `P` 控制在 95 以下。

玩家回到稳定 W 状态的二楼主卧外。门内传来女人询问父母是否回来，门外同时响起敲门，林远箭头指向门内。门槛两侧时代不一致，所有声音都没有同步实体源。

玩家需要完成三项主动观察：确认电话已断、检查窗外真实光向、核对门框两侧材质。随后选择退回客房并保持不回应。玩家没有替回放补上“回来的人”，记忆第一次继续运行到声音停止。

天光变化后，门内外同时恢复为现代，两个空间锚点关系正确。玩家穿过客房门，在现实 06:10 从床上醒来。订单仍是一晚住宿，手机日期进入第二天，第一夜留下的规则纸不存在。窗框旧钉孔仍在，作为唯一无法完全解释的痕迹。

制作人员表出现，游戏结束。
