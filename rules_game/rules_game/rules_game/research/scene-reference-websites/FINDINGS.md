# 洋楼场景参考与现成素材网站

## Summary

针对《规则之间》的上海旧洋楼、民宿改建、庭院与两夜探索，优先使用谷德和 ArchDaily 核对建筑关系，80.lv 研究游戏场景制作与灯光。
现成素材优先查 Fab 与 Blendkit；免费材质、环境照明和部分模型优先查 Poly Haven 与 ambientCG。
Poly Haven、ambientCG 资源为 CC0；Fab、Blendkit、Sketchfab 需要按具体许可处理。Blendkit 为 BlenderKit 当前官方名称。
现有 HTML 样片会暴露内嵌资源，适合优先使用 CC0；免版税资产需确认原始资产分发限制。

## Findings

以下网站用途与优先级是针对当前项目的建议，不表示已选购或导入任何资产。

| 网站 | 当前项目用途 | 费用与许可 | 建议检索词 |
|---|---|---|---|
| 谷德 gooood | 上海洋楼、院落、改建痕迹、主辅楼关系、真实平面 | 建筑案例与照片参考；未发现允许直接制作游戏贴图的统一授权 | 老洋房、上海、院落、旧宅改造 |
| ArchDaily | 平面、剖面、挑空、楼梯与回廊关系 | 作为建筑参考，照片署有摄影版权 | Shanghai villa renovation、courtyard house、adaptive reuse |
| 80.lv | 游戏场景的资产拆分、材质、灯光与制作过程 | 本次核验文章可公开阅读；文章图片不是素材授权 | mansion environment、horror interior、environment breakdown |
| Virtual Shanghai | 上海历史照片、街景与生活环境线索 | 检查每项来源与权利，不将可浏览等同于可商用 | villa、residence、interior、1937 |
| Fab | 建筑模块、家具、植物、现成室内与庭院资产包 | 免费和付费；Standard 允许商业项目并支持兼容工具，禁止单独再分发资产；另有 CC BY | old house、modular interior、wooden stairs、vintage furniture、garden |

| ambientCG | 地板、砖墙、石材、铺路、旧化表面等材质 | 免费 CC0，可用于商业游戏并包含原始资产文件 | Wood、Plaster、Bricks、PavingStones、Tiles |

谷德的 House of Attila 案例由设计事务所提供，项目位于上海，记载建筑始建于1923年，总项目面积500㎡，由两层主楼与三层辅楼组成。挑空中庭、室内外庭院与玻璃顶连接使它很适合参考当前扩大的主辅楼方案；现代办公用途和当代装修不能作为1937年原貌证据。

ArchDaily 的 HCCH 上海洋房改造案例由建筑师提供说明，适合研究挑空、回廊、楼梯和框景。该建筑属于1990年代建造的三层建筑，不能误标为战前洋楼。

80.lv 的 Mansion Environment 作者访谈解释了场景布局、资产制作、材质和每个房间的灯光目标；可借鉴不同空间的氛围分工。Forest Home 作者访谈可补充建筑外部、植被与夜景，但其废弃森林住宅气质与仍营业民宿不同。

## Insights

- 建筑案例解决尺度、邻接与视线，游戏美术案例解决可读性与氛围；将二者对照更适合当前项目。
- 优先确定一组木作、门窗和家具的共同语言，再补零散道具，有助于避免现成素材拼接后的年代与比例冲突。
- 当前网页样片优先用 CC0，能减少内嵌资源与原始资产分发许可的冲突；具体付费资产仍需逐项核对。
- 主楼、玻璃过渡、院落与服务翼能形成不同空间气质，但实例本身不能替代任务距离与实走节奏验证。

## Strongest objection

现成场景常围绕展示镜头设计，未必适合连续第一人称探索；套用整套欧美古宅也可能削弱上海民宿的身份。参考图与许可合适仅是第一步，还需验证年代、比例、拆件、导入与实际通行。
