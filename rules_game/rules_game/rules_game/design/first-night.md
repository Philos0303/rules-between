## 1. 这一夜讲完什么

玩家黄昏自助入住上海一栋由旧私人洋楼翻修成的小型民宿。热水和照明故障起初可以用房屋老化解释。林远留下的提醒第一次救了玩家，使玩家愿意依赖规则。随后，年代更早的另一种笔迹给出相反的经验，环境也开始重放旧生活。玩家逐渐发现，所谓规则是两位来过这里的人在不同条件下总结的办法。

**表线故事闭环**：入住受困 → 相信林远 → 遇到不能照抄的经验 → 重走他的生存路线 → 在最后一次遮光回放中守住自己的位置 → 验证真实清晨并离开。表线玩家能够知道林远确实找到过安全出口，也能理解规则为何需要现场验证。没有镜子、没有完成里线操作，清晨就没有可通行的历史门。

**里线故事闭环**：追查另一种笔迹 → 看见早期女性探索者曾经成功的方法和后来失效的条件 → 走出她反复走错的路径 → 找到她留下的镜子 → 验证镜中画面属于过去 → 发现林远拿到过同一面镜子，而且在可以离开时主动返回 → 定位历史入口。玩家由此产生具体问题：镜中那个一直在等电话的家庭究竟经历了什么，为什么这些普通生活会困住后来的人？这个问题留给第二夜。

“表线/里线”是调查深度；“M/W/G”是环境状态，两者不一一对应。表线也会遇见战时渗入，里线也有大量现代场景。

### 1.1 三个人必须分清

| 人物 | 本夜承担的内容 | 呈现 | 本夜不能暗示成什么 |
| --- | --- | --- | --- |
| 战时无名女人 | 异常来源的生活残留；父母不在身边，一个人应付无法控制的时代 | 旧电话短句、遮光痕迹、未用的餐具；仅提供来源方向 | 幕后出题者、恶鬼、早期探索者、必须救出的任务对象 |
| 更早的女性探索者，稿内简称“早期住客” | 里线的主要人物；留下原始记录和镜子，最终迷失 | 较旧的便笺、客房中的生活痕迹、路线图 | 战时女人本人；全错的规则作者 |
| 林远 | 整理生存办法，确实抵达安全出口，选择历史门，后来在第二夜因污染迷失 | 后加的字迹、便携录音机、一张离开前的末页 | 第一夜逃生失败者、实时与你通话的人、主角 |

早期住客的确切姓名与到访年份不设谜题。两种笔迹同时用纸张、署名/无署名和笔记分类区分，不依赖颜色。第一夜给出林远主动留下的证据，但不伪造第一夜现场能够证明他第二夜全部遭遇的材料。

| 项目 | 当前决定 |

## 2. 玩家操作、时间与触发总约定

### 2.1 玩家实际能做的动作

移动、观察、交互、打开笔记、暂停。交互根据物体提供明确动词：查看门缝、打开/关上、拿取、拨动开关、拉合窗帘、播放/停止、放置镜子、比较痕迹。选择文字用于物体操作，不另做对话树。门可以“打开至观察位置”与“穿过”；危险门槛前移动会停住，必须另按交互才能跨越，避免走路误触死亡。

物品自动使用，不做格子背包、耐久、弹药、合成或自由组合。手电无电量。镜子只在指定的观察位可使用，其他地方提示“这里没有适合对照的固定位置”，不提供全场景实时镜面。

### 2.2 三种时间

- **故事钟**：阶段表中的 17:40、20:30 等标签。只在完成阶段出口条件时跳转，不按现实时间跑完整一夜。
- **预计游玩时间**：给制作和试玩的估计，不是触发器；读得慢不会死亡，不会自动错过里线。
- **演出时间**：开灯后 1 秒声响、敲门组之间 2 秒等短延迟。暂停、文本查看、镜面对照、应用失焦时全部暂停。没有限时答题或必须在几秒内反应的生死窗口。

等待天亮是有明确前提的物体动作。玩家不能从入住直接睡到成功：第一次“休息”进入第一夜；之后床只保存/回顾，不跳过未解决阶段。最后安全空间恢复后，坐到客厅沙发并选择“等到天亮”才推进到清晨。等待本身无死亡分支。

### 2.3 事件共同格式

阶段事件均为一次性：满足前置条件 → 玩家进入指定触发范围并主动操作 → 展示预兆 → 可观察/撤回 → 明确行动 → 结算 → 写稳定检查点。单纯读到未来线索、提前开过门或在地图上走过，不越级触发后续危险。

“现场确认”指玩家交互观察具体证据并完成相应动作，例如看见门缝地面与门框连续后打开门；不要求在笔记中答选择题，不以收集文本数量解锁。重复操作只重播信息，不重复领取污染减免或推进时间。

完成一个阶段只使下一阶段就绪；真正的故事钟/F跳转发生在下一段入场动作，期间可插入里线。入场动作依次为：A06→N1；A09返回客厅→首敲21:10；A13→N2；A20开始听门→N3；A25上楼→N4；A28完成电话核对（或A27后的循声选择）→N5；A35启动外圈路线→N6；A42坐下整理→N7；A48等待→N8。入场提交阶段和稳定点后才播放危险。N5的C5统一在U6电话桌旁建立，不要求踩进回路。

### 2.4 第一夜始终成立的四条规律

| 规律 | 实际判断 | 不能代替它的经验 |
| --- | --- | --- |
| T1 门槛连续 | 两侧处于同一稳定层，地面/门框与光源关系相接，才跨越 | 敲了几次、声音像谁、门里看起来明亮 |
| T2 遮光边界 | W遮光状态下，不让室内灯光跨过窗线；封好窗后室内灯仍可用 | 任何时候都不开灯，或任何时候都立刻开灯 |
| T3 实体声源 | 器械动作/播放状态与声音同步才证明声音来自那里；录音也不代表本人在场 | 熟悉的声线、听见自己的房号、旧记录说跟着走 |
| T4 连续路径 | 两个固定地标的方位和连接关系一致才前进；错位时退回最后稳定处 | 永远左转、只跟箭头、不许回头 |

M是现代民宿，W是过去生活的稳定回放，G是二者无法连续的夹缝。回溯可以在玩家不移动时覆盖同一地点，如A42；这不等于允许玩家硬跨M/W断裂门槛。第一夜的错误规律不随机，重试保持同一因果。

### 3.3 门和捷径状态

- N0：玄关电子锁、U2 用订单自动解锁；公共空间自由通行。F9 服务门、U3/U4/U5 房门、U5 阳台门、O2–O3 侧巷门用 I2。F5 后门内侧插销和 F9–O5 内侧插销可直接操作；F9 未开前自然无法从内侧接近后者。
- I2 放在 F8 电箱旁透明应急钥匙盒内，同时能开电箱盖。打开盒盖即可拿取；维护说明可见，不做密码谜题。N0 可看见但操作提示为“有故障时按自助说明使用”；玩家若坚持提前取出也允许，门提前开启不推进夜间事件。N2复位前必须实际开电箱盖，因此通关者必定拿到I2，N5不会被锁在没有钥匙的阳台上。
- O5–O1 从 O5 一侧拔门闩后永久成为双向捷径。即使 N2 已打开，N6 仍有新状态下的返回验证；不强迫重新锁门找钥匙。
- 院门在N1/N2只是内侧锁扣卡住，给出故障提示，无空间循环或污染。N3起可开到观察位置，门外属于G：路牌和排水沟关系错乱。玩家先看见断接证据，可取消；仍选择“走向路灯”才被短黑场送回O1，首次+5，其后不重复扣值、不推进阶段。这是一次无法深入的软返回，不存在第二道致命确认边界。清晨才变为连续M出口。N0休息前回院门只提示“是否结束本次入住并回主菜单”，取消继续；这不记剧情结局。
- O6 始终在 O3 的 D07 实体围挡之后：玩家可走到围挡前查看林远的折返痕迹，不能穿过门洞、翻越或走入 O6；不设计车祸或空气墙死亡。

### 7.1 历史门的资格公式

`unlock_now = dawn_reached AND mirror_owned AND mirror_past_verified AND mirror_limit_verified AND wall_compared AND threshold_aligned`

`history_ready = history_ready_previous OR unlock_now`

`history_passable = history_ready AND threshold_aligned AND history_door_open`

所有变量均为布尔值，默认false；结果也为布尔值。history_ready是已经获得的资格，保存后不会因收镜清零；threshold_aligned是本次两侧均W且砖缝/灯影已核对的现场状态，关门或退回M后清零。history_door_open由打开/关门交互写入。进入承诺只读history_passable。例：完成H6后两者均true；收镜返回玄关后ready仍true、passable=false；重开已知门并核对W/W后passable恢复true。

| 变量 | 成立的实际动作 | 不允许替代为 |
| --- | --- | --- |
| dawn_reached | A48 完成，已进入 N8 | 现实电脑时间到了清晨 |
| mirror_owned | H3 真实取出镜子；放在托位仍算拥有 | 只读到“镜子”二字 |
| mirror_past_verified | V1 镜中旧柜与现实两处痕迹比对 | 收齐 D1/D2/D3 |
| mirror_limit_verified | V2 核对真实墙面并收镜，理解旧门未接通 | 必须先犯错或死亡一次 |
| wall_compared | V3 看两处补缝并检查旧门轮廓 | 随机对每面墙按交互 |
| threshold_aligned | V3 站立区与门内均 W、地缝及灯影核对完成 | 镜中有门就直接通过 |

V1/V2可互换调查次序，两个实际比对各自成立即可。wall_compared只由V3动作3实际检查轮廓写入；提前看到门影不写。V3缺少某个条件时，托位允许随时收镜去补；不会把唯一镜子锁在尚未打开的门旁。

没有 hidden_score、纸张数或强制死亡数。H1/H2 提供发现路径和故事，它们不作为硬收集门槛。认真检查暗格并独立完成三次镜面对照，也算玩家实际走了里线；不能要求背答案的玩家装作不知道。

### 7.2 第一夜独立版本的实际结束

- 未解锁历史门：只呈现 E1“离开”。完成生存，不加“普通/坏结局”标签。
- 解锁后仍离开：仍然是 E1，结尾回顾多一条“我找到了另一条路，但这次离开了”。这是一项调查记录，不新增第三种结局。
- 解锁后选择进入：在门前显示清楚的承诺文字：“继续探查这栋房子的过去。当前版本到此结束。”选择“继续”后，门后旧灯与电话声播放 6 秒以内，黑场显示“第一夜结束 · 历史入口已找到”，进入制作人员表；**不显示可游玩的第二夜按钮，不装载空场景**。

## 8. 死亡、错误和精神污染的精确定义

### 8.1 这五种行为始终安全

查看、阅读、听录音、停在观察位置、打开笔记/暂停。慢走、反复比对、正常探索空房同样不加 P。镜子不按使用秒数收费，也不制造“为了看剧情必须污染到某个数”的要求。

### 8.2 污染数值

P 为整数 0–100；F 为阶段下限；阶段表决定 F。P 表示记忆重叠程度，不是临床诊断。玩家默认在笔记看到“清醒/轻微错位/回溯渗入/方位失稳/接近迷失”五段，可选明确区间提示。

| 操作 | 精确结算 | 次数限制 |
| --- | --- | --- |
| 进入阶段 | P = max(P, F_new) | 每阶段一次；旧阶段已完成不再入场 |
| 首次夜间试院门 | P = min(99, max(F, P + 5)) | 整个第一夜一次，其后仅软返回 |
| 跨入一个已展示预兆的错误观察前沿 | P = min(99, max(F, P + 8)) | 每个遭遇首次计；撤回后重复首次动作只复现警告，不重复扣值 |
| 正确完成 A32、A39、A45 | P = max(F, P - 8) | 每个完成标志一次；不能反复开关灯刷值 |
| 在稳定点主动“整理一下” | P = max(F, P - 12) | 每阶段一次；不推进故事钟、不清危险事件 |
| 警告后主动执行 X1–X4 的深走/加强危险动作 | P = 100，立即进入迷失死亡流程 | 不依赖初始 P；这是放弃最后退路的承诺动作 |
| 读档恢复 | P = max(F_saved, min(P_saved, F_saved + 8)) | 同时恢复稳定快照；避免反复载入濒死起点 |

本稿不另外设置“站着等到 P=100”的死法。100 由明确的致命行为到达；若未来导入或调试状态出现 P≥100，只能进统一失败恢复，不保存为可继续的稳定档。低污染也不能把明显断裂的门当安全，高污染也不能让正确操作突然变错。

表现档沿用 0–19、20–39、40–59、60–79、80–99。第一夜强度还受章节上限限制：N0–N2 不显示完整回溯和空间复制；N3 只门外错层；N4 才启用声音和镜中旧景；N5 才有短廊复制；N7 才有连通生活区回溯。即使反复犯错提高 P，也不能提前剧透后段。高 P 仅增加边缘重复/环境低频声，不遮住门框、窗线、固定锚点或文字。

**例子**：正确玩家到 N5，P=60；误走一次 P=68，正确退回 P=max(60,68−8)=60。到 N7，F=68；两次不同遭遇的首次误判使 P=84，仍然有所有退路；窗帘扣好后点灯永远安全。首次误判即使从 P=96 开始也只到 99，不会未经第二次承诺直接杀死玩家。

## 9. 检查点、回溯和不被卡住的条件

### 9.1 保存内容与时机

- 刚进入O1时建立启动档。C0前提前取钥匙/镜子，更新该启动档的物品事务，恢复位置仍在O1；因此早期探索后退出也不会丢失物品。
- C0–C8 是阶段稳定快照，发生在危险前。保存阶段、F/P、正常门锁/插销、灯/窗帘、已完成交互、背包、已获取笔记和镜面比较结果。
- 阶段入场快照包含“入场演出待播放”。危险中死亡后载入，会从对应稳定点重播这段入场，不因一次性标志已消耗而停在空事件。普通恢复不重新播放已完成的其他阶段。
- 在无危险的稳定节点拿到 I2/I3/I4、完成 H4/H5/H6 后更新同一流程档及该阶段的稳定快照；不另造大量存档槽。H3 保存的镜子归属须与暗格显隐同一笔完成。
- 危险警告、跨门、G 回路内部、镜面动画中不写位置存档。退出游戏时保留最新稳定快照；重开从那里恢复，不把角色放在夹缝里。
- 保存对话/笔记自动收录的新知识可以独立追加；载入时知识保留，物品与可走门恢复快照。笔记若引用尚未重新取得的物品，标“曾经看过”，不凭知识生成物品。
- 最晚取得镜子后已有稳定快照，所以后续 V2/V3 死亡不会要求重找镜子。H4/H5 的完成也各自更新，避免因 H6 错误重做三次对照。
- H6解锁时不把人物存进W门槛：给清晨快照追加资格和镜子位置，恢复出生点仍F2，S恢复M、历史门关闭、threshold_aligned=false。当前正在玩的画面不被这次后台保存打断；重载后只需去检查已知门。进入预告或E1前都保留这份清晨快照，尾声不能覆盖它。
