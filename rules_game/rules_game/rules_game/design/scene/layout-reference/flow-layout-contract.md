# 第一夜流程与房间布局合同

本文件把[完整游玩流程](../../first-night.md)逐段映射到[米制几何](../geometry.json)。它记录已确认流程在空间中的落位，不替代后续灰盒试玩或模型验收。

机器可读路线见[flow-routes.json](flow-routes.json)。`nodes`只包括实际能步行抵达的节点，所有跨门路线都必须对应`geometry.json.openings`中的门洞。窗外、镜面、围挡后的目标是观察证据，绝不能被实现为额外可走房间。

## 可建造的路线骨架

```text
室内生活环
F1 — F2 — F3 — F4 — F8 — F1
               |          |
              F5 — F6    F9 — F10
               |
              O2 — O3 — O4 — O5 — F9
                   |          |
               D07围挡        O1 — F1
                 透视O6

二层安全回路
S — U1 — U6
    |     |
   U2    U8 — U5 — U1
   U3    
   U4
   U7
```

这一骨架有三个不同目的。F1/F2/F3/F4/F8给第一夜前半段提供短距离的反复对照；U6/U8/U5把“不能沿旧经验走”变成一次看得见、能撤回的局部绕行；O2/O3/O4/O5提供林远的外圈验证。O6刻意不接进环路。

## 表线能否完整承载

`flow-routes.json.phases`的N0–N8均给出逐节点路径。关键结果如下：

- N0至N4只使用已开放的F1/F2/F3/F4/F5/F6/F7/F8、S、U1/U2/U6/U7/U8。U2看O1，U6/U8看O2，两种视线不会混用。
- N2取得I2后，F9/F10、U3/U4/U5和侧巷门才成为常规可用空间。A15的前院路灯经F1正门观察，而不是在F8伪造外窗。
- N5的危险段只挂在U6—U1。正确路U6—U8—U5—U1完全由D28和D27构成，D27使用已取得的I2；因此玩家不会被设计成必须试错。
- N6从F10经F5/O2/O3/O4/O5/O1回F2。D07是可检查的封闭边界，O3—O4—O5始终保留真实可走的外圈。
- N7故意缩到F1/F2/F3，其他门只允许观察和退回。N8恢复全部正常边，表线E1只需要F2—F1—O1的真实清晨连续性。

镜子三观察点维持为定点旧景，建模不需要全屋实时镜面，也不能把V2的过去窄门做成现代可走第三门。S的历史墙必须遵从`geometry.json.stair.history_wall_field`：它位于北侧完整墙面，净高2.15米，不在任何斜梯底下。

## 建模前必须遵守的观察位

- **A04 / U2**：W10南向O1的视线不要被高柜、厚窗帘或床头挡住；画面至少看出门廊、院墙和院门方向。路灯与排水沟仍由O1和D01观察位承担，不应为了U2镜头移到窗前。
- **A15 / F1**：D01能够开到安全观察角，F1内地面、门框与O1路灯要能同时进入近景；F8只做电箱、钥匙盒和维护标签，不加外窗。
- **A31 / U6—U1**：站在D25的U6侧时，U1的真实D22门牌、楼梯上口栏杆/地板接缝和可叠加的G复制门框必须在有限转身范围内看清。复制构件只在G态出现，M态不留伪门或外窗。
- **A37 / O3**：D07要做物理围挡和可读折返痕迹；其后可见的O6只需约一小截封闭路面与远景，导航/碰撞止于O3侧。
- **V1/V2/V3**：F4压痕区、U5梳妆台托位、S补缝观察位都必须留出玩家站立和回退空间。固定镜景的家具位置服从`placements.json`，门窗和墙体服从`geometry.json`。

## 验证边界

本合同已通过几何字段和门洞邻接的文本核对，且`../../../tools/verify_geometry.ps1`可用于检查基础几何约束。它没有替代目标引擎灰盒实走：实际玩家视野、门扇开启范围、家具碰撞、异常构件在D25观察位的可读性和节奏仍须在灰盒中验证。
