上海旧宅民宿 / 第一夜 / 场景设计与建模交接

《规则之间》场景制作参考

一栋洋楼，四间客房，室内与院巷逐步开放。表线完成生存，里线追查前人并以旧手镜辨认历史入口。

外观图用于材质与尺度气质参考；下方正交图与几何数据控制实际门窗、墙线和空间关系。此包交付设计图片与文字，不代表 Blender 模型或 目标引擎 场景已制作验收。
