# 《规则之间》项目约定

项目根为本文件所在目录。先读README.md、design/game-design.md和design/first-night.md；空间工作再读design/scene/README.md。

- 当前保留基线由负责人于2026-10-21确认：两位前人、表里双线、三处手镜对照、唯一主楼梯。第一夜行为以first-night.md为准，几何与陈设分别以scene/geometry.json和scene/placements.json为唯一源。
- 第二夜仅保留方向和入口，未知内容保持待定。重构引擎和架构未选定，不恢复旧公寓、旧门户或旧存档接口作为约束。
- 已授权的普通可逆工作直接完成。改变剧情、玩法、空间范围或费用的关键选择再询问；共创保留用户指定的决策点。
- 保留证据、退路、可访问性和动态件分离。设计确认、静态检查、运行验证与玩家验收分别报告，不能相互替代。
- 修改设计数据后运行tools/verify_project.py与相关几何检查。几何或摆放变化后按需重建图文；不恢复会覆盖源数据的一次性迁移。
- 仅加载本任务直接相关资料。无需通用Agent框架、角色树、旧生产状态或占位模板，不自动创建这些内容。
- 子代理仅在当前会话获准且有明确独立任务时使用。不得自动提交、推送、下载付费资源或对外发送消息。
- 资源保留可追溯来源；参考图不是已交付模型。清理前核对绝对路径与归属，保留被引用内容和有用回滚备份。
- 使用简洁中文，先交付结果；结束时删除本次无用临时文件。
